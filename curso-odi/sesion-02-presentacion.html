Hay cuatro tipos que vamos a usar siempre. Numéricos: se miden con números, como irradiancia, temperatura o kW. Categóricos: pertenecen a un grupo, como cielo despejado, parcial o nublado. Supervisado y no supervisado

Supervisado

Los datos traen la respuesta. El modelo aprende a predecirla, como los kW de generación.

No supervisado

No hay respuesta. El modelo busca grupos o patrones por sí solo.

¿Cuál uso?

Pregúntese: ¿tengo una variable objetivo con valores conocidos?

Sesión 2 · Análisis y tipos de datos

En el aprendizaje supervisado los datos traen la respuesta y el modelo aprende a predecirla, como los kW. En el no supervisado no hay respuesta y el modelo busca grupos o patrones por sí solo. Para decidir cuál usar, pregúntense: ¿tengo una variable objetivo con valores conocidos?
